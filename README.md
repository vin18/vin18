# Vinit Raut

**Backend / Distributed Systems Engineer** — fintech & trading systems by day, building low-latency infrastructure for fun.

I work on distributed, high-throughput backend systems in the fintech space, with a focus on correctness under concurrency, event-driven architectures, and systems-level performance. Outside of work I build portfolio projects that push into territory my day job doesn't cover — matching engines, streaming pipelines, and systems programming in Rust and Go.

Currently targeting senior/staff backend roles at infrastructure, dev-tools, and fintech startups (US/EU).
